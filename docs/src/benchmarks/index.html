    How to read this benchmark

    Each point represents one archived run on a UTC date. Total runtime is the wall clock for the entire benchmark. Solver statuses describe why the optimizer stopped. Verification outcomes describe what the run established about each input.

    Outcome counting changed on July 14, 2026. On July 18 the objective changed from finding the closest adversarial example to checking feasibility within a fixed budget, and outcome counting changed again. Machine and dependency changes can also affect nightly timings. Use the paired performance reports to measure the effect of individual changes such as PR #278.

    Gaps mean the metric was unavailable. A line at zero means the run recorded zero. If a date has several runs, the chart uses the last archived result for that day.
